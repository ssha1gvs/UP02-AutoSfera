# Учебная практика УП.02 | Вариант 12
## Автоматизация учета и управления продажами в автосалоне «АвтоСфера»

- **Год:** 2026

### Краткое описание
Информационная система «АвтоСфера» предназначена для автоматизации ключевых бизнес-процессов автосалона: ведение каталога автомобилей, оформление сделок купли-продажи, управление складскими остатками и формирование отчётности. Система поддерживает ролевую модель доступа (администратор и менеджер) и обеспечивает хранение данных в централизованной базе.

### Стек технологий
- **Моделирование бизнес-процессов:** Draw.io, Visual Paradigm (IDEF0, IDEF3, DFD, UML)
- **Прототипирование интерфейса:** Tailwind Play
- **Разработка:** C#, Windows Forms (.NET Framework)
- **База данных:** SQLite (прототип), перспектива MySQL
- **Планирование:** Kaiten (диаграмма Ганта)
- **Контроль версий:** Git, GitHub
